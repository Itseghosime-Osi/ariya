# Usability test script: invitation studio

Run with 5 people (ideally couples or planners, at least 2 on a phone). Fictional event data only. Do not use real guest links or pass codes. Nothing here has been run yet; checklist item M3 is closed only when results are filled in.

## Setup

- A test event named "Ada & Kunle", venue "The Lagos Event Centre".
- One phone (390 × 844) and one laptop. Screen and voice recorded with consent.
- Say only: "Think out loud. I can't help, but I'll note where you get stuck."

## Tasks (read one at a time)

1. **Change the names.** "The card should say Chika & Tobi. Change it."
2. **Move something.** "Move the date a bit lower on the card."
3. **Change the colour.** "Make the card look more green."
4. **Export for printing.** "Get a file you could send to a printer."
5. **Share on WhatsApp.** "Get a small picture you could send to a friend on WhatsApp."

## Record per task

| Measure | How                                                               |
| ------- | ----------------------------------------------------------------- |
| Success | Finished without help (yes / with a hint / no)                    |
| Time    | Seconds from reading the task to done                             |
| Stalls  | Where they paused more than 5 seconds, and what they said         |
| Errors  | Wrong controls tried, undo used                                   |
| Words   | Any label they did not understand (feeds the microcopy pass, L13) |

## After the tasks

- "What was the easiest part? The most confusing?"
- Rate ease from 1 to 5.
- "Where would you look for help?" (checks the Help button and `?`).

## Pass bar to aim for

Tasks 1, 4 and 5 done unaided by at least 4 of 5 people; every stall logged and ranked in the checklist.
