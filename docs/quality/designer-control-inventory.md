# Invitation studio control inventory

This records the controls currently offered by `feat/studio-pro-designer`. It explains scope; it is not acceptance evidence. The [283-item matrix](designer-test-matrix.csv) records what has actually been verified.

| Area              | Current controls                                                                                                                                     | Boundaries                                                                                                                                                                                                                                                                                                                                                                             |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Starting document | Event invitation template; Simple/Pro; optional paper/canvas settings                                                                                | No required blank-document or paper-selection step                                                                                                                                                                                                                                                                                                                                     |
| Documents         | Editable JSON backup; File → Open Design Backup; imported card artwork; undoable template reset                                                      | Imported card images are flattened artwork. No PSD, editable SVG, RAW or multi-page import/export                                                                                                                                                                                                                                                                                      |
| Shapes            | Rectangle, ellipse, line, arch, star, diamond, crest, triangle; geometry selector; fill and outline                                                  | Presets have fixed geometry. No path nodes, Bézier handles, Boolean operations, star-point count, dashed/cap/join/alignment controls                                                                                                                                                                                                                                                   |
| Drawing           | Click or drag; Shift equal-sided shapes; Alt from centre; Escape/cancel/blur cleanup                                                                 | Line drawing is a simple shape; there is no path-editing or pixel-painting tool                                                                                                                                                                                                                                                                                                        |
| Transforms        | Eight local-axis resize handles; numeric geometry; aspect lock; dedicated centre rotation handle; flips; proportional group scaling                  | No configurable transform origin or outside-bounds rotation gesture. Alt suppresses movement snapping; it does not duplicate                                                                                                                                                                                                                                                           |
| Corners           | Four radius widgets; linked or independent radii; numeric values                                                                                     | Supported for rectangles and applicable image frames; not a generic path-corner editor                                                                                                                                                                                                                                                                                                 |
| Text              | Five font choices; size/weight/italic; left/centre/right; tracking/line height; case; colour and styling                                             | Whole-layer formatting. No rich character ranges, justified text, underline/strike controls or text on a path. Fonts have CSS/system fallbacks                                                                                                                                                                                                                                         |
| Pictures          | PNG/JPEG/WebP; orientation handling; contain/cover; focal positioning; replacement; frame masks; border/corners                                      | No standalone pixel crop session or background removal. Canvas size & ratio resizes the document. Existing public-image sharing is retained                                                                                                                                                                                                                                            |
| Colour            | HEX/RGB and colour panel; foreground/secondary swatches; reset/swap; native eyedropper where available; linear/radial presets and CSS gradient field | No saved custom palette or graphical gradient-stop/handle editor. The OS eyedropper is browser-dependent                                                                                                                                                                                                                                                                               |
| Layers            | Selection, rename, visibility, lock, ordering, duplicate/delete; groups; align/distribute                                                            | One level of grouping; no nested groups, channels, smart objects or raster/vector masks. Alignment reference is defined by the current command, not a switchable mode                                                                                                                                                                                                                  |
| View              | Fit/document-pixel zoom; hand/Space/wheel pan; rulers/grid/guides; navigator artwork/viewport                                                        | No pointer-anchored zoom mode. Device and stylus acceptance remains open                                                                                                                                                                                                                                                                                                               |
| Effects           | Opacity, 12 blend modes, blur, soft/foil/glow presets, custom shadow, brightness/contrast/saturation/warmth; image frame masks                       | These are static CSS-rendered effects. No retouching filters, liquify, perspective/warp, editable masks or style clipboard                                                                                                                                                                                                                                                             |
| Output            | PNG, JPEG, editable JSON; flattened PDF at 5 inches wide and 300 DPI; cancellation/errors; allocation limits                                         | No editable vector PDF, selectable export multiplier, batch processing or animation/video timeline. Large images may be capped; the dialog reports output dimensions                                                                                                                                                                                                                   |
| Guest passes      | One entry-seal layer; sample artwork in editor; guest-specific code after acceptance                                                                 | Sample exports are not guest passes. Personal PNGs are verified against the actual local guest code; opacity, blur, mirroring and low-contrast colours cannot erase the seal. Rotation-aware paper bounds and foreground/backing protection are implemented. Party/companion/dietary revision checks pass. Mixed-group edge cases, tiny output and physical-camera/print checks remain |

The comparison checklist retains unoffered features as **Not applicable**, rather than marking them as completed. Introducing one later requires updating both this inventory and its acceptance status.
