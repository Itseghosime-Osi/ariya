# Core journey: Event → Template → Edit → Preview → Export or Share

This is the path a host follows. Counts are taps or clicks, not typing, and come from the studio as it is today (checked in a browser for the studio part; the steps before the studio come from reading the app's routes, not from a timed run).

| Step        | What the host does                                                                   | Taps       | Notes                                                                                                               |
| ----------- | ------------------------------------------------------------------------------------ | ---------- | ------------------------------------------------------------------------------------------------------------------- |
| 1. Event    | Opens the event and chooses its invitation                                           | about 2    | Event page, then the invitation card. Counted from the routes, not measured.                                        |
| 2. Template | Lands in the studio with the event's template already filled in (names, date, venue) | 0          | Template-first: nothing to choose before editing. A different layout is one tap in Pro (Stationery Layout Presets). |
| 3. Edit     | Taps a line on the card or a field in Simple mode, types                             | 1 per line | Simple mode shows the words as plain fields. The card saves by itself.                                              |
| 4. Preview  | Looks at the card on the canvas; optional "see it as a guest"                        | 0          | The canvas is the preview. A separate guest preview does not exist yet (checklist L11).                             |
| 5. Export   | Export, choose a format, Download                                                    | 2          | PDF is selected by default. The dialog says what the file will be before it downloads.                              |
| 5b. Share   | Small for WhatsApp, Download                                                         | 3          | Under 400 KB.                                                                                                       |

**Studio only (steps 2 to 5):** open, change one line, Export, Download = 3 taps plus typing.

## Steps that could be removed or merged

- Choosing a format could default to the last one used.
- The guest preview (step 4) is the one missing step.

## What is not known

Where people stall. That needs the usability test in `designer-usability-test.md`, so checklist item L1 stays open until it has been run.
