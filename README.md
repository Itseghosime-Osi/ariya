# OwambePlan

In-house experiment for Tech4Youth Edo, Module 06, Project 36: a wedding and event planner where every guest RSVPs with a personal link.

## What's here

`index.html` is "The Yes", a scroll-driven 3D story built with Three.js (r128) and GSAP ScrollTrigger (3.12.2), both loaded from cdnjs. Seven chapters:

1. The box: a ring box opens
2. The yes: the ring rises
3. The noise: a family WhatsApp group floods the screen
4. The calm: the messages scatter
5. The link: the camera dives into the diamond and a personal invitation appears
6. The count: a reception hall fills seat by seat
7. The dance: confetti

## Run it

Open `index.html` in a browser, or serve the folder:

```
npx serve .
```
